# Plano — index.html (Portfólio Arcade)

- **Rota/arquivo:** `index.html`
- **data-page:** `portfolio`
- **Componentes:** HUD de sistema, header fixo, hero split, perfil, mission select (projetos), laboratório bento, arsenal, trajetória, contato e footer conectado.
- **Seções e ordem:** hero → sobre → projetos → laboratório → arsenal → trajetória → contato → footer.
- **Tokens 60-30-10:** base `#070b14` (60%), superfícies `#101828` / `#162033` (30%), acentos ciano `#00f0ff`, magenta `#ff2e88`, amarelo `#ffe600` e lima `#7dff5b` (10%).
- **Animações 60Hz:** anime.js para entrada/stagger, IntersectionObserver para reveals, apenas `transform` e `opacity`, `prefers-reduced-motion` desliga tudo.
- **Assets:** `assets/profile.jpg` otimizado (640×640), ícones SVG inline, favicon SVG, anime.js e Vivus locais.
- **SEO/OG/JSON-LD:** `Person`, title, description, Open Graph, Twitter Card e favicon.
- **Critério de pronto:** LCP < 2.5s, CLS < 0.1, 60fps no scroll, navegação por teclado, contraste AA, sem frameworks de UI e sem dependência de serviços externos.
- **Escopo editorial:** portfólio 100% autoral, sem menções, marcas ou links de outros sites/projetos.
