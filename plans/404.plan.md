# Plano — 404.html

- **Rota/arquivo:** `404.html`
- **data-page:** `404`
- **Status:** concluído
- **Objetivo:** transformar uma rota inexistente em uma tela de arcade clara, com caminhos úteis de volta ao portfólio.
- **Componentes:** header HUD compartilhado, tela de erro com pixel-art, código 404, mensagem, terminal de sugestões, ações e footer compartilhado.
- **Seções e ordem:** tela 404 → sugestões → ações → footer.
- **Conteúdo:** “SINAL PERDIDO”, explicação curta, links para home, projetos, contato e currículo. Sem culpar o usuário, sem jargão técnico excessivo.
- **Interações:** links diretos, botão de voltar, reveals, animação de glitch desligada em `prefers-reduced-motion`.
- **Tokens 60-30-10:** base escura, superfícies, acentos magenta/ciano/amarelo.
- **Animações:** glitch CSS no número 404, cursor piscando, anime.js opcional; `prefers-reduced-motion` desliga.
- **Assets:** SVG inline, favicon e fontes locais.
- **SEO/OG/JSON-LD:** `noindex, follow`, title e description.
- **Acessibilidade:** contraste AA, foco visível, links com texto claro, sem depender apenas de cor.
- **Responsividade:** código 404 escala com `clamp`, ações empilhadas no mobile.
- **Critério de pronto:** página abre sem erros, links funcionam, sem overflow em 390 px, visual coerente com o restante do site.
