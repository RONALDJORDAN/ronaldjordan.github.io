04 // NOTAS TÉCNICAS

ANOTAÇÕES DE CAMPO

Regras curtas que uso para tomar decisões. Abra cada nota para ver o raciocínio por trás.

LOG DE APRENDIZADO
Performance é parte da experiência

Uma interface bonita que trava não é uma boa interface. Méso antes de otimizar, prefiro animações de transform e opacity e defino um orçamento de performance antes de adicionar efeitos.

HTML primeiro, JavaScript depois

Conteúdo e navegação devem funcionar mesmo sem JavaScript. O JS entra para melhorar a experiência, não para ser a única forma de acessar o site.

Local-first quando faz sentido

Nem todo problema precisa de nuvem. Arquivos locais, rede doméstica e processamento no dispositivo podem ser mais rápidos, mais privados e mais simples de manter.

Acessibilidade não é um extra

Contraste, foco visível, navegação por teclado e textos alternativos são requisitos de qualidade. Um site acessível é um site melhor para todo mundo.

Documentar é reduzir futuro retrabalho

Uma decisão explicada economiza horas de arqueologia. README, comentários pontuais e registros de arquitetura valem mais do que uma pasta cheia de arquivos sem contexto.
